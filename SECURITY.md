# Security policy

Please don't report a security problem in a public issue.

Report it privately through GitHub instead: open the repository's
**Security** tab and choose **Report a vulnerability**. Describe the problem,
the OrcaPod version and device you found it on, and the steps to reproduce it.
You'll get a reply as soon as possible, and we'll keep you posted on the fix.

A problem in a third-party library should also be reported to that library's
maintainers. A problem that also affects the upstream slicing engine should
also be reported to [OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer/security).
